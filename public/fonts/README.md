# Typography

DM Sans and Instrument Serif are self-hosted under the SIL Open Font License. The corresponding OFL files are included in this directory.

Sources: [DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans) and [Instrument Serif](https://github.com/google/fonts/tree/main/ofl/instrumentserif), retrieved September 10, 2026 through Google Fonts. WOFF files were losslessly packaged from the provided TrueType outlines. No external font requests are made by the website.
